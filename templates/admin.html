Format any mounted directory (external USB drive, secondary HDD mount, NFS/SMB share) into the Mateo file structure and optionally choose it as the active save target.

Will create: videos/, music/, photos/, files/, incoming/, user_drive/.

How Mateo Storage Works

Mateo structures all storage into 6 dedicated categories: videos/, music/, photos/, files/, incoming/ (torrents), and user_drive/ (personal user files). When you choose a storage device as the Active Target, all new uploads and torrent downloads are saved directly onto that device. Existing files remain streamable, and you can scan and index files on any connected drive into the database library at any time.
